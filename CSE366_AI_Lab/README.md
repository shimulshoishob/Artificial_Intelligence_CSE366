# CSE366 Artificial Intelligence — Lab Files

Setup (once):  pip install numpy scikit-learn matplotlib   (Python 3.10+)

Each LabXX folder has:
- LabXX_....docx : the lab sheet (theory, code, expected output, viva questions, exercises)
- README.md      : the same lab sheet in Markdown
- *.py           : runnable code; open a terminal in that folder and run  python <file>.py

CSE366_AI_Lab_Manual.docx : all six labs in one document.
